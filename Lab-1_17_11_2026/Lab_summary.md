### Theory

During the first lab class for **CSE 3154 (Web Programming)**, our instructor walked us through the overall structure of the course and what we are going to cover throughout the semester. Because it is a 1.50-credit lab course with 3 contact hours per week, the main goal is to build practical skills in creating dynamic, interactive, and data-driven web applications rather than just static pages.

Sir explained the full roadmap of topics included in the course syllabus:

* Setting up local server environments like **IIS** and **XAMPP** so we can run and test web applications right on our own machines.


* Client-side scripting using **DHTML with JavaScript**, focusing on form handling, input validation, built-in objects, and event handling to make web pages responsive to user actions.


* Understanding how web programs run in a web environment, including the structure and anatomy of a **PHP** page.


* Working with **HTML forms** and connecting web applications to a **database** so user data can be stored, retrieved, and managed properly.


* Exploring server-side programming with **Servlets**, along with more advanced concepts like **XML**, **AJAX** (for updating parts of a page asynchronously without full reloads), and **Web Services** for exchanging data between systems.



### Discussion and Conclusion

This introductory session gave us a clear picture of how all the pieces of web programming fit together—from setting up a local server and designing interactive front-end behavior to handling backend logic, databases, and asynchronous data exchange. Having this overview right at the start helps us see why each topic matters before diving into individual lab tasks. Overall, the first lab set a practical foundation for the course, and we now have a clear idea of what skills we will be building in the upcoming sessions.
